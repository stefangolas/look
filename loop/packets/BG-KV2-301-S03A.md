## Section 2 — Tier 1 (`kernel/tier1.rs`, NEW)

Theorem 9.1 as an LP over two cached `Cone`s: feasible d iff there is
d in R^3 with d.(n1 x n2) != 0 for all n1 in Cone1, n2 in Cone2. The
enclosure-safe formulation: the cross-product cone of the two cones'
boundary generators has its minimum |d.(n1 x n2)| bounded below iff the
cones' angular separation is positive — implement as the CONE-SEPARATION
test (the two cones' axis angle vs half_angle sum, with the cross-cone
tightening per Sederberg-Meyers/Hohmeyer lineage named in spec section 23):
compute the minimal angle between the cone of possible n1 x n2 vectors and
the zero direction via the axes/half-angles in closed form (arccos is a
transcendental? NO — work in cos-space: the comparison |axis1.axis2|
against cos(half1+half2+...) is pure polynomial/trig-free arithmetic on
cosines; the fixtures supply axis/half-angle data directly. NO angle
functions anywhere — the test is a cos-space inequality, H-3-noted).

Deliverables:
- `pub fn tier1_loop_free(c1: &Cone, c2: &Cone) -> ClaimVerdict<
  TierOneCert, Degeneracy, Reason>` where `TierOneCert { d: [f64; 3],
  min_dot: f64 }` (a feasible transversal direction with its certified
  positive lower bound — min_dot > 0 via the cos-space test at
  TOL_JACOBIAN floor).
- Infeasible -> `Inconclusive(Degeneracy)` (the tangential-adjacent case;
  routes to Tier 2, S3b's business).
- `pub fn boundary_seeds(p: &dyn CertifiedPatch, q: &dyn CertifiedPatch)
  -> Construction<Vec<PointCert>>` — section 9.3: every edge of P against
  Q as an R8 problem. v1 SHAPE (honest scope): the edge set arrives as a
  caller-supplied list of (BezierLeaf1 curve, chart id) pairs from the
  leaves' boundaries — this packet does not enumerate B-rep edges from

  supplied edge via `krawczyk_c1_n3` with subdivision to DEPTH_MAX,
  collecting Proven PointCerts. The `boundary_seed_completeness_matches_
  oracle` test: a fixture pair with a known count of edge crossings

  it a known number of times) — seeds found == oracle count, each
  certified.
